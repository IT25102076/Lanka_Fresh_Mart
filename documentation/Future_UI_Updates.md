# Future UI Updates & Enhancements

This document tracks ideas, improvements, and validation rules that we plan to add to the User Interface in the future. 

As we progress through the sprints, we can pick items from this list to polish the application.

## 1. Authentication & Registration
- [ ] Add strict validation for Email (e.g., must contain `@` and a valid domain format).
- [ ] Add strict validation for Phone Numbers (e.g., specific length, numeric only, Sri Lankan format `+94...`).
- [ ] Add password strength indicator (minimum length, special characters, uppercase/lowercase).
- [ ] Show/Hide password toggle button.

## 2. Product Management
- [ ] Add image preview when uploading/entering a product image URL.
- [ ] Add client-side validation to ensure prices cannot be negative.
- [ ] Add sorting and filtering (by category) on the Admin Product List.

## 3. Cart & Catalogue
- [ ] Show a dynamic badge on the Cart icon in the navbar indicating how many items are in the cart.
- [ ] Add a confirmation modal when clicking "Empty Cart".
- [ ] Display a toast notification instead of a full page reload when adding an item to the cart.

## 4. General UX
- [ ] Implement a Dark Mode toggle.
- [ ] Improve mobile responsiveness for the Data Tables.
